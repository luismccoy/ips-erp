State Transition Permissions

Admin Permissions

  • • SUBMITTED → APPROVED
  • • SUBMITTED → REJECTED
  • • MANUAL_REVIEW → PENDING (RIPS)
  • • DEFENSE_GENERATED → APPROVED_FOR_SUBMISSION

Nurse Permissions

  • • Create DRAFT visit
  • • DRAFT → SUBMITTED
  • • REJECTED → SUBMITTED (resubmit)
  • • AVAILABLE ↔ ON_VISIT ↔ BREAK

System/AI Permissions

  • • PENDING → VALIDATING (RIPS)
  • • VALIDATING → GENERATED
  • • REJECTED → ANALYZING (Glosa)
  • • ANALYZING → DEFENSE_GENERATED
  • • Auto-sync: OFFLINE ↔ ONLINE

Invalid Transitions (Guarded)

These transitions are prevented by the system to maintain data integrity.

❌ Cannot Skip States

  • • DRAFT → APPROVED (must submit first)
  • • REJECTED → APPROVED (must resubmit)
  • • DRAFT → REJECTED (must submit first)

⚠️ Cannot Reverse

  • • APPROVED → any prior state (final)
  • • SUBMITTED → DRAFT (can only be approved/rejected)
  • • DISCHARGED → ACTIVE_CARE (re-admit process)
